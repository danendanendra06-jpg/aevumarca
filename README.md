# AevumArca

AevumArca is a blockchain-based time capsule dApp that allows users
to preserve immutable messages and personal goals on BOT Chain with a timestamp and creator wallet address.

## How It Works

1. Connect your MetaMask wallet.
2. Make sure you are connected to BOT Chain Mainnet.
3. Write a message.
4. Submit the message to save it on-chain.
5. The message is stored permanently on-chain with the creator wallet address and block timestamp.

## Features

- Connect MetaMask
- Create an on-chain time capsule
- View stored capsules
- Store creator wallet address
- Store timestamp
- BOT Chain Mainnet integration
