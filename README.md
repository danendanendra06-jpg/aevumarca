# AevumArca

AevumArca is a blockchain-based time capsule that allows users
to preserve messages on BOT Chain with a timestamp and wallet address.

## How It Works

1. Connect your MetaMask wallet.
2. Make sure you are connected to BOT Chain.
3. Write a message.
4. Submit the message.
5. The message is stored on-chain with the creator wallet
   address and timestamp.

## Features

- Connect MetaMask
- Create an on-chain time capsule
- View stored capsules
- Store creator wallet address
- Store timestamp
- BOT Chain integration
